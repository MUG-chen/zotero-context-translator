# Zotero Context Translator 0.2.0 安装与使用

## 系统要求

- Windows 64 位
- Zotero 9.0.x（验收基线：9.0.6）
- 带有可选中文本层的 PDF
- 一个 OpenAI Chat Completions 兼容接口

插件不包含 OCR。扫描版 PDF 会显示“无法访问 PDF 文本层”，不会静默上传整篇论文或调用其他 OCR 服务。

## 0.2.0 持久翻译卡片

0.2.0 将临时选区入口与翻译结果彻底分离。选中文本时，Zotero 原生标注栏下方只显示一个紧凑的“译 翻译”按钮；点击后才创建完整翻译卡片并调用 API。活动卡片从创建起挂载在 Reader 的持久浮层中，因此在同一论文内继续选择或标注其他文字时，加载中的请求和已有译文都不会消失。

同一时间只保留一张活动卡片。点击另一段文字的翻译触发器会取消旧请求，在原卡片当前位置开始新翻译；普通选区不会触发替换。切换到另一篇论文并选择文字时会关闭旧论文卡片。新翻译保留卡片的位置和宽度：用户手动设置的高度会保留，自动适配高度则从紧凑状态重新增长。

## 0.1.9 拖离卡片自动适配译文

0.1.9 修复了在翻译完成前拖出卡片时，译文区域仍被锁定在加载阶段高度的问题。首段译文、说明或错误信息出现后，卡片会保持当前宽度和左上位置，仅按内容向下增高；高度最多为 520px 或 Reader 视口高度减 24px，超过后在卡片内部滚动。

自动增高不会主动缩短卡片。拖动卡片仍从当前位置开始，底部可以超出 Reader 视口，但标题栏会保持可找回。用户从右下角主动调整尺寸后，当前卡片会尊重该尺寸；新选区会重新使用自动适配模式。

## 0.1.8 紧凑浮窗与尺寸调整

0.1.8 将翻译卡片默认宽度从 440px 缩小为 380px、最大高度从 620px 缩小为 520px，并适当收紧字体和留白。点击“翻译”后，卡片会继续留在 Zotero 原生标注框中，加载状态和译文不再突然分离或改变宽度。

如需移动卡片，可拖动标题栏；超过拖动阈值后卡片才会分离。分离后的卡片可从右下角调整大小，最小尺寸为 320×240px，并会始终限制在 Reader 视口内。关闭后不会保存用户调整的尺寸，新选区仍从紧凑默认布局开始。

## 0.1.6 初始状态实际隐藏修复

0.1.6 修复了 0.1.5 中 `hidden` 属性被浮窗自身 `display: flex` 样式覆盖的问题。初始状态行现在通过实际显示样式隐藏，同时从 DOM 中清空“选择一种翻译方式”文案；点击“翻译”后的连接、生成、完成和错误状态仍会正常显示。请用 0.1.6 替换 0.1.5，并重新打开已有的 Reader 标签页。

## 0.1.5 初始状态精简

0.1.5 隐藏了浮窗初始状态下重复的“选择一种翻译方式”提示及圆点，不再保留空白占位。点击“翻译”后，连接、生成、完成和错误状态仍会正常显示。

## 0.1.4 单一翻译入口

0.1.4 删除了“词语”“整句”“段落”和“解释”四个效果重叠的模式按钮，改为一个明确的“翻译”主按钮。选中文本只会打开浮窗并在本地准备上下文，不会自动调用 API；只有点击“翻译”或设置页的“测试连接”才会产生请求。内部统一采用结合标题、摘要、章节和邻近段落的上下文翻译。

## 0.1.3 最终关闭按钮修复

0.1.3 修复了关闭按钮位于可拖动标题栏内时，标题栏错误执行 `setPointerCapture()`、导致真实鼠标后续 `click` 被重定向的问题。现在从关闭按钮等交互控件开始按下时不会启动标题栏拖动或捕获指针；标准点击、键盘激活和 `Esc` 关闭保持不变，普通标题区域仍可拖动。该修复增加了真实事件来源回归测试，并在 Zotero 9.0.6 隔离 Reader 中重新验证首击关闭。

## 0.1.2 修复与改进

0.1.2 取消了会误杀正常流式翻译的 60 秒总超时：请求需在 90 秒内产生第一个有效模型事件，开始输出后只有连续静默 45 秒才会中断。尚未收到模型输出时，502、503、504 和临时连接错误最多自动重试两次；429 会在安全范围内遵守 `Retry-After`。窗口会显示连接、思考、生成和重试状态，并在流中断时保留已收到的译文。

浮窗已重做为“学术阅读卡片”：原文可展开，译文与说明分区显示，支持复制、错误重试、深色模式和更清晰的键盘焦点。修复了初始嵌入 Zotero 选区弹层时，关闭按钮因 `pointerdown` 与 `click` 之间移动 DOM 而间歇失效的问题。

## 0.1.1 修复说明

0.1.1 修复了 0.1.0 中两个会阻断主要功能的问题：设置页现在按照 Zotero 插件片段的 `showing` 生命周期初始化，“保存设置”和“测试连接”可以正常使用；Reader 选区坐标会先从阅读器 JavaScript 域安全复制，实际划线选择可以弹出浮窗。请勿继续安装 0.1.0。

## 安装

1. 下载 `zotero-context-translator-0.2.0.xpi`。
2. 在 Zotero 中打开“工具 → 插件”。
3. 点击右上角齿轮，选择“Install Add-on From File…”（从文件安装插件）。
4. 选择 XPI 文件并确认安装。
5. 打开“编辑 → 设置 → 上下文翻译”。

从 0.1.x 升级时直接选择 0.2.0 XPI 即可；插件 ID 不变，因此已有 Base URL、Model Name、目标语言、缓存和 Login Manager 中的 API Key 会保留。

插件只声明支持 Zotero 9.0.*。如果 Zotero 拒绝安装，请先确认版本是 9.0.x，而不是旧版或尚未验收的新主版本。插件通过 GitHub Release 更新清单检查新版本，也可直接选择新版 XPI 覆盖安装。

## API 设置

需要填写三个字段：

- `Base URL`：可以是版本根地址，例如 `https://api.example.com/v1`；也可以直接填写完整的 `/chat/completions` 地址。
- `API Key`：保存在 Zotero 使用的 Firefox Login Manager 中，不写入普通首选项、日志或论文缓存。
- `Model Name`：第三方接口实际支持的模型名。

默认目标语言是简体中文。插件只支持 OpenAI 兼容的 Chat Completions/SSE 格式，不支持厂商专有协议。

点击“测试连接”会发送一次明确的最小请求，最多生成 1 个 token。第三方服务仍可能计费。仅打开设置页、打开论文、选择文本或建立本地索引都不会产生 API 请求。

## 阅读与翻译

1. 在 Zotero Reader 中选中单词、句子或段落。
2. 原生标注栏下方会出现一个紧凑的“译 翻译”按钮。
3. 点击该按钮后才会调用 API，并在按钮下方展开完整翻译卡片。
4. 结果在同一张持久卡片中流式显示，不会切换成右侧栏；同一论文中的普通新选区不会关闭卡片。

鼠标按下触发器或卡片按钮时会保留 PDF 原选区，插件不会自动创建高亮或下划线标注。原文默认显示三行，可展开或收起；译文可一键复制，错误卡片可直接重新尝试。卡片可拖动并从右下角缩放，支持内部滚动、关闭按钮和 `Esc` 关闭。点击另一选区的翻译触发器才会复用卡片并替换结果；切换到其他附件并产生选区或关闭 Reader 会清理旧卡片和监听器。

## 本地上下文与缓存

插件在后台建立本地结构索引，包括：

- 基于页面持续纵向空白带推断的单栏、双栏和三栏阅读顺序
- 通栏标题、栏内顺序和 PDF 行末断词修复
- 标题、摘要和章节路径
- 按页/栏、标题、行距、首行缩进和常见学术行内标题重建的当前段落及邻近段落
- 论文概况和建议术语

优先使用 Zotero 条目中的标题和摘要；缺失时从 PDF 文本层推断。摘要以 `Abstract`、`Keywords`、`Introduction` 和后续章节标题等多种边界信号确定。索引按附件 key、文件大小和修改时间生成指纹。文件发生变化后会重新建立缓存。

缓存位于 Zotero profile 下的 `zotero-context-translator-cache`，不写 `zotero.sqlite`，也不持久保存完整翻译历史。可在设置页重新分析当前论文或清除可丢弃缓存。

## 隐私与网络行为

- 后台索引完全在本机运行。
- 只有点击“翻译”或“测试连接”时才访问所配置的 API。
- 请求使用受字符预算限制的标题、摘要、章节路径、当前选区和邻近文本，而不是默认上传整篇 PDF。
- 论文内容在提示词中被标记为不可信数据，不能覆盖系统翻译策略。
- 插件不会把 API Key 写入错误信息或调试日志。

请根据论文的保密要求选择可信的 API 服务商。第三方接口的数据保留政策不受本插件控制。

## 故障排查

- **没有翻译触发器**：确认 PDF 可以正常复制文本；扫描版 PDF 不在 0.2.0 支持范围内。
- **401/403**：检查 API Key，或清除后重新保存。
- **404**：检查 Base URL 和 Model Name。
- **429**：尚未收到模型输出且 `Retry-After` 不超过 15 秒时，插件会在最多三次总尝试范围内自动重试。
- **502/503/504**：通常是接口临时繁忙；插件会在没有模型输出时自动重试两次，并显示当前尝试次数。
- **等待响应超时**：90 秒内只有连接保活而没有有效模型事件时停止；可在错误卡片中重新尝试。
- **流式响应中断**：模型开始输出后连续 45 秒没有新数据时停止，并保留已经显示的译文。
- **上下文过长**：插件会先移除远端段落；超过 8,000 字符的选区会明确拒绝，不会静默截断。
- **章节判断不正确**：在设置页点击“重新分析当前论文”。复杂排版仍可能退化为标题、摘要和邻近段落上下文。

## 适配边界

布局判断是页面自适应的，不针对某一论文写死栏宽或栏距；自动化样例覆盖单栏文本片段、窄栏距双栏、三栏提示、通栏块和行内 `Abstract`，并用一篇 21 页真实双栏论文做端到端验收。

但 0.2.0 不能承诺处理所有 PDF：扫描件、损坏或乱序文本层、旋转侧栏、杂志式自由排版、跨页表格、文字转曲线以及只存在于图片中的公式/图注可能无法正确进入结构索引。若结构索引失败或在 15 秒内未完成，插件会停止并显示错误，不会发送一次缺少上下文的 API 请求。涉及保密或高精度术语时，应抽查首次生成的标题、摘要和章节效果。

## 卸载

在“工具 → 插件”中移除 Zotero Context Translator。卸载流程会清除专用 Login Manager realm 中保存的 API Key。若还要删除本地结构缓存，可先在设置页点击“清除可丢弃缓存”。
