# Zotero Context Translator 验收规范

## 发布原则

以下任一必需项失败，均不得把构建标记为正式可用。自动化测试不能替代 Zotero Reader 实机验证。

## 自动化门禁

在仓库根目录运行：

```powershell
npm test
npm run build
```

必须满足：

- 所有 Node 测试通过。
- XPI 根目录包含 `manifest.json`、`bootstrap.js` 和 `prefs.js`。
- XPI 不包含 API Key、缓存、日志、测试、`work/` 或用户论文。
- 401/403、用户取消和首个模型事件后的流中断不重试；尚未收到模型事件时，502/503/504 或临时连接错误最多重试两次；短暂 429 遵守不超过 15 秒的 `Retry-After`。
- 在 429 或临时 5xx 的退避等待中取消，应在 1 秒内结束，且不得再发出下一次请求。
- 首个有效模型事件必须在 90 秒内到达；SSE keep-alive 不算模型事件。模型开始后不设总时长上限，连续静默 45 秒才中断。
- `reasoning_content` 只用于显示“模型正在分析论文上下文”状态，不得展示或记录思维内容。
- 用户取消信号在整个 SSE 生命周期内有效。
- 响应元数据损坏时保留可见译文，且不写入损坏的结构化字段。
- 启动中途失败时回滚 Reader 监听器和首选项面板；结构索引失败或超时不得调用 API。
- 当前段落必须由视觉行重建，且不得跨页、跨栏或越过章节标题。
- 设置页必须通过 Zotero 片段的 `showing` 事件初始化，并在重复显示时只绑定一次按钮。
- Reader 浮窗必须通过 iframe 发出的真实 `customEvent` 跨域路径验证；直接调用 `_dispatchEvent` 不能作为唯一验收路径。
- 初始嵌入原生选区弹层时，关闭按钮连续首次点击 20 次必须全部关闭；按钮按下与点击之间不得移动浮窗 DOM。
- 关闭按钮等交互控件的 `pointerdown` 不得启动标题栏拖动或调用 `setPointerCapture()`；非交互标题区域仍必须可以拖动。
- 浮窗必须只包含一个“翻译”按钮，不得出现“词语”“整句”“段落”“解释”模式控件或 `data-mode` 状态。
- 初始 `ready` 状态必须在实际计算样式中隐藏完整状态栏，并从 DOM 清空“选择一种翻译方式”，不显示圆点或空白占位；`loading`、`result` 和 `error` 状态仍必须显示。
- 选择文本只建立本地上下文，不得调用 API；点击一次“翻译”必须只产生一次统一的上下文翻译请求。
- 学术阅读卡片必须分离原文、译文、说明和错误区域，并验证原文展开、译文复制、手动重试、深色模式和窄视口。
- 长译文、展开原文或 Reader 缩小时，浮窗四边必须保留至少 12px 可见边距，正文区域独立滚动；所有按钮点击目标至少 36px。
- 复制成功时只写入译文；剪贴板不可用或写入失败时必须显示“复制失败”，不得误报成功。
- 100 次选区、50 次翻译、5 个文档后只有一个活动浮窗，关闭后无监听器和请求泄漏。

## 性能门槛

| 指标 | 发布门槛 |
|---|---:|
| 插件新增启动时间 P95 | ≤ 300 ms |
| 浮窗出现时间 P95 | ≤ 100 ms |
| 缓存章节查找 P95 | ≤ 20 ms |
| 上下文构建 P95 | ≤ 50 ms |
| 30 页结构索引 | ≤ 5 s |
| 100 页结构索引 | ≤ 15 s |
| 缓存重新加载 | ≤ 200 ms |
| 主线程单任务 | ≤ 100 ms |
| 100 页峰值新增内存 | ≤ 100 MB |
| 关闭后残留新增内存 | ≤ 30 MB |
| 取消到停止回调 | ≤ 1 s |

Node 合成基准用于验证算法回归；PDF.js 提取时间、主线程长任务和内存必须在 Zotero 9.0.6 实机测量。

## Zotero 9.0.6 实机门禁

使用独立 profile 和独立空数据目录：

1. 安装 XPI，验证启用、禁用、重启、卸载和再次安装。
2. 确认设置页字段完整；API Key 输入为掩码；未点击“测试连接”时无网络请求。
3. 打开单栏、双栏、元数据缺失和扫描版 PDF。
4. 选择单词、句子和段落，记录 Reader 事件的字段名和类型，不记录论文文本。
5. 验证浮窗在选区附近出现且只有一个“翻译”按钮；划线后请求数为 0，点击一次后请求数为 1，按钮点击不取消高亮，结果不进入右侧栏。
6. 验证首次关闭 20/20、拖动阈值、原文展开、译文复制、错误重试、内部滚动、键盘焦点、`Esc`、新选区替换和附件切换清理。
7. 关闭 Reader 标签页，确认浮窗随页面卸载且不残留文档监听器。
8. 首次打开建立结构索引；第二次打开命中缓存；修改附件指纹后重新索引。
9. 对扫描版 PDF 显示明确的不支持信息，且不调用 API。
10. 使用本机 OpenAI 兼容模拟服务验证慢首包、keep-alive、503 后恢复、活动长流和部分流中断；不得使用用户真实 API Key。

## 验收语料

- 合成布局样例：单栏文本片段、窄栏距双栏、三栏提示、通栏块、行内摘要以及 30/100 页索引负载，用于可重复算法基线。
- 用户明确授权的 21 页 USENIX Security 论文：真实双栏、封面页、可选中文本层、PDF 标题元数据为空，用于标题/摘要回退、章节路径和缓存命中验证。论文正文不得进入仓库或发布包。
- 扫描版占位样本：用于确认 OCR 不支持提示。

## 记录模板

最终验收报告至少记录：

- Zotero、Windows、CPU、内存、Node 版本
- XPI SHA-256
- 自动化测试总数和结果
- 每项性能实测值、P95 采样数和通过/失败
- 每种语料的索引时间、缓存加载时间、章节路径和回退原因
- 网络请求次数、取消时间和错误策略
- 已知限制及未通过项
